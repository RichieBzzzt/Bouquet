# Bouquet

A floral-inspired Visual Studio Code theme with both dark and light variants.

## Themes

- **Bouquet** — the original dark theme
- **Bouquet Light** — a light green-based theme

Both themes target WCAG 2.2 AA contrast levels: 4.5:1 for normal text and 3:1 for large text.
